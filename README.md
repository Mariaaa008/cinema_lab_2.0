# cinema_lab_2.0
ИВТ-262, выполнили Волкова К, Дмитриева Д, Ливченко М, тема: Система бронирования билетов в кинотеатр
**1 Общие сведения**
**1.1.	Основание для выполнения работ**
Автоматизация процесса бронирования билетов на киносеансы, повышение качества обслуживания посетителей.

**1.2 Заказчик работ**
Заказчик: кинотеатр.

**1.3 Сведения об источниках и порядке финансирования**
Источник финансирования определяется Заказчиком.

**1.4 Цель выполнения работ**
Целью выполнения работ является предоставление информационной системы для бронирования билетов с возможностью выбора даты, времени, мест в зале, а сотрудники, в свою очередь, могли управлять расписанием фильмов.

**1.5 Состав работ** 
1) Разработка технического задания;
2) Разработка веб-интерфейса клиента;
3) Разработка интерфейса администратора;
4) Тестирование и исправление выявленных ошибок;
5) Развертывание системы.

**1.6  Сроки выполнения работ** 
В таблице  представлены этапы выполнения работ. 
| № этапа |	Наименование этапа |	Срок сдачи работ |	Результат работ |
|:---:|:---:|:---:|:---:|
| 1 |	Определить требования |	1 день |	Список функций |
| 2 |	Проектирование системы |	15 дней |	Пробная модель интерфейсов |
| 3 |	Разработка системы |	Не более 35 дней |	Рабочий сервис | 
| 4 |	Проверка работы системы |	Не более 5 дней |	Результаты тестирования |
| 5 |	Развертывание системы |	Не более 10 дней |	Адаптированный под пользователей сервис |

**1.7 Место выполнения работ** 
Работы выполняются на территории Российской федерации.

**2 Назначение системы**
Система предназначена для упрощенного бронирования билетов в кинотеатр, с целью автоматизации продаж и резервирования мест на киносеансы. 
Пользователь будет иметь доступ к расписанию сеансов, схеме залов, информации о свободных местах. После выбора пользователь может оформить бронь и оплатить билеты.
Администратор должен иметь возможность добавлять и изменять фильмы и сеансы.
