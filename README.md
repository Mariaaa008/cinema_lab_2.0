Целью выполнения работ является предоставление информационной системы для бронирования билетов с возможностью выбора даты, времени, мест в зале, а сотрудники, в свою очередь, могли управлять расписанием фильмов.

**2 Назначение системы**
Система предназначена для упрощенного бронирования билетов в кинотеатр, с целью автоматизации продаж и резервирования мест на киносеансы. 
Пользователь будет иметь доступ к расписанию сеансов, схеме залов, информации о свободных местах. После выбора пользователь может оформить бронь и оплатить билеты.
Администратор должен иметь возможность добавлять и изменять фильмы и сеансы.

**3 Описание системы**
**3.1 Схема предоставления услуги**
Клиент заходит на веб-сайт. На сервере хранятся данные о фильмах, сеансах, местах и прочей информации. При оформлении заказа система взаимодействует с платежными сервисами и уведомлениями. 

**3.2 Сценарии использования услуги**
**3.3.1 Регистрация клиента (не обязательно)**
Действующие лица: Клиент и/или Администратор. 
Инициируется пользователем.
Основные шаги:
1.	Клиент открывает форму регистрации.
2.	Вводит имя, номер телефона или адрес электронной почты.
3.	Проверка данных.
4.	После успешной регистрации клиент получает доступ к личному кабинету.
	
**3.3.2 Авторизация (не обязательно)**
Действующие лица: Клиента и/или Администратор.
Инициируется пользователем.
Основные шаги:
1.	Клиент вводит логин/электронную почту и пароль.
2.	Проверка учетной записи.
3.	При успешной проверке открывается личный кабинет.
4.	При ошибке высвечивается окошко невозможности входа.
   
**3.3.3 Поиск фильма и сеанса**
Действующие лица: Клиент и/или Администратор. 
Инициируется пользователем. 
Основные шаги:
1.	Клиент выбирает дату.
2.	Система отображает доступные фильмы и сеансы.
3.	Клиент выбирает фильм и время.
4.	Система отображает зал и схему доступных мест.
   
**3.3.4 Выбор и бронирование места**
Действующие лица: Клиент и/или Администратор. 
Инициируется пользователем. 
Основные шаги:
1.	Клиент выбирает одно или несколько свободных мест.
2.	Система временно резервирует выбранные места.
3.	Система показывает стоимость заказа и срок действия брони.
4.	При успешной оплате места переводятся в состояние «Продано».
5.	При истечении времени бронирования без оплаты места освобождаются.
   
**3.3.5 Оплата билетов**
Действующие лица: Клиент и/или Администратор. 
Инициируется пользователем. 
Основные шаги:
1.	Клиент подтверждает заказ.
2.	Система передает запрос в платежный шлюз.
3.	После подтверждения оплаты система фиксирует заказ.
4.	Формируется электронный билет с уникальным идентификатором/QR-кодом.
5.	Клиент получает уведомление и может просмотреть билет в личном кабинете или в электронной почте
   
**3.3.6 Отмена бронирования**
Действующие лица: Клиент и/или Администратор. Инициируется пользователем. Основные шаги:
1.	Клиент открывает список заказов.
2.	Выбирает заказ, доступный для отмены по правилам кинотеатра.
3.	Система проверяет возможность отмены.
4.	После отмены места становятся доступными для повторного бронирования.
5.	При необходимости запускается процедура возврата денежных средств.
   
**3.3.7 Управление расписанием администратором**
Действующие лица: Клиент и/или Администратор. Инициируется пользователем. Основные шаги:
1.	Администратор авторизуется.
2.	Создает или изменяет сведения о фильме.
3.	Выбирает зал, дату и время сеанса.
4.	Система проверяет пересечения сеансов и доступность зала.
5.	После сохранения сеанс становится доступным клиентам.
